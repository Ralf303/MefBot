# Админка Pablo

Отдельное приложение Express: `npm run admin`. Оно не запускает бота, его cron и Telegram polling. Слушает только `127.0.0.1:3091`. Nginx направляет исключительно `/admin/` в этот процесс, существующие `/` и API на 8080 сохраняются.

Настройки входа находятся в игнорируемом `.env.admin`, образец — `.env.admin.example`. Данные MySQL и Redis берутся из `.env.prod`. Пользовательские ID и Telegram ID не редактируются, чтобы не нарушить связи. Пароли игровых ролей не возвращаются в браузер.

## Возможности

- Статистика пользователей, регистраций, балансов, вещей, кейсов, чатов, семей и записанных платежей. Данные кешируются на 30 секунд. «Профили обновлены» считает `updatedAt`, а не уникальных активных игроков.
- Поиск и страницы пользователей; редактирование всех игровых числовых параметров, имени и username.
- Просмотр, выдача, изменение, передача и удаление вещей. Проверка вместимости, пересчёт занятых слотов, снятие конфликтующей одежды и сброс кеша изображений.
- Каталог вещей с изображениями и отдельными профилями экземпляров.
- Кейсы, дома, видеокарты, стойки, игровые роли, таймеры бонусов, активность и ранг в семье. Удаление карты освобождает её стойку.
- Чаты: VIP, срок VIP, кейсы, игры, банк, имя и ссылка.
- Семейные балансы и улучшения; журнал игровых операций и отдельная история правок администратора.

Сохранение меняет только поля, отредактированные в форме. В транзакции блокируется актуальная запись и проверяется каждое исходное значение: при конкурентном изменении сервер возвращает 409 вместо перезаписи. Запись истории создаётся в той же транзакции.

Сессия действует 12 часов, хранится на сервере и сбрасывается при перезапуске админки. Cookie — Secure, HttpOnly, SameSite=Strict с областью `/admin`. Изменения требуют CSRF-токена. Вход ограничен по числу попыток. Изображения доступны только после входа и только из каталога `img`.

Для первого запуска создаётся только собственная таблица `adminAudits`; другие таблицы приложение не мигрирует. Изменения каталога типов вещей через UI не предусмотрены, редактируются отдельные экземпляры. Удаление пользователей и чатов отключено.
